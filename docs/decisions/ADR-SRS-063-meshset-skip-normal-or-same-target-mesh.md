# ADR-SRS-063: 省略の判定に使う解析済みウィンドウメッシュ集合を限る

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-03 |

## Context

[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) は各コーナーパターンの試行前に、候補ウィンドウの存在メッシュコード集合が、蓄積済みの `.meshset` ファイルのいずれか 1 件に含まれれば、そのパターンをスキップする
（[ADR-SRS-046](ADR-SRS-046-analyzed-window-meshset-skip.md)）。根拠は「解析しても新たな情報が得られない」ことである。

通常解析（[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)。解析識別子 `3-<メッシュコード>`）には対象ピーク絞り込みが無く、per-mesh CSV には解析対象メッシュ全体の地理的範囲内のピークが出る。
`key_col_resolved=false` の行は一次フィルタを通らずに無条件に出る（[FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用)）。
一方、広域解析の per-mesh CSV は、その対象メッシュの対象ピークの行だけを出す（[FR-007](../20_SRS.md#fr-007-per-mesh-csv-出力プロミネンス閾値適用) の対象ピーク絞り込み）。

そのため、ある対象メッシュ A のパターンで窓 S を解析すると、`.meshset` には S が残るが、per-mesh CSV には A の対象ピークしか出ない。
後で処理する別の対象メッシュ B（S の中のメッシュ。同じ N の後の対象メッシュか、次の N）のパターン W の存在メッシュ集合が S に含まれると、W はスキップされる。
S の解析では B の対象ピークを出していないので、B の対象ピークは結果を得ないまま進み、最悪は N=6 の後の不備ゲートで未確定として現れる。
起きるのは、近くに未確定の対象メッシュが 2 つあり、窓が海岸沿いで同じ範囲になるときに限られるが、規則どおりに起きる帰結である。
HLD 3.14 の計画レビュー（2026-10-03）で見つかった。

## Decision

1. [FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) のスキップ判定に使う `.meshset` を、次のどちらかに当たるものに限る。
   - 通常解析のもの（解析識別子が `3-` で始まる）
   - 同じ対象メッシュの広域解析のもの（解析識別子 `<N>-<対象メッシュコード>-<コーナー>` の対象メッシュコードが、試行中の対象メッシュと同じ。N とコーナーは問わない）
2. 判定に使う `.meshset` は、ファイル名の解析識別子で選ぶ。判定は従来どおり、候補集合が選んだファイルのいずれか 1 件に含まれるかで行う（部分集合判定）。`.meshset` の内容と形式は変えない。

理由: 対象ピークは通常解析で `key_col_resolved=false` だったピークである。
通常解析の窓 S に候補集合が含まれれば、対象メッシュも S に入り、その対象ピークは S の通常解析の per-mesh CSV に `key_col_resolved=false` の行として出ている。
同じ対象メッシュの広域解析は、前の N の段でも、その時点の対象ピーク（次の段の対象ピークを含む）を出している。
どちらも「解析しても新たな情報が得られない」が対象ピークについても成り立つ。

## Alternatives

**(A) 対象ピークの集合も `.meshset` に持たせ、試行中の対象ピークがすべてその中にあるときだけスキップする**

却下。対象ピークの組は対象メッシュごとに分かれ、別の対象メッシュの組とは重ならないので、判定の結果は本 ADR と同じになる。`.meshset` の形式を変える分だけ重い。

**(B) スキップをやめる**

却下。[ADR-SRS-046](ADR-SRS-046-analyzed-window-meshset-skip.md) が省いた再解析（N=5 の窓が N=4 の窓と重なる場合など）を戻す。

## Consequences

- 別の対象メッシュの広域解析の窓を根拠にスキップしなくなる。海岸沿いで窓が重なる対象メッシュが近くにあると、その分だけ解析が増えうる。
- N=5 で N=4 の同じ対象メッシュの配置と完全に重複するケースは、従来どおりスキップされる。
- 反映先: [SRS FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の入力表と「無効パターンのスキップ」、[SRS 8.1](../20_SRS.md#81-内部データ一覧) の No.13、
  [ADR-SRS-046](ADR-SRS-046-analyzed-window-meshset-skip.md) の補足、[ST](../70_ST.md) の `ST-FR-014-07`・`ST-FR-014-10`・`ST-FR-014-11`、
  [HLD 3.4](../30_HLD.md#34-fr-004-33メッシュ結合解析オーケストレーション) の `.meshset` の形式と [HLD 3.14](../30_HLD.md#314-fr-014-広域結合解析オーケストレーション)。
