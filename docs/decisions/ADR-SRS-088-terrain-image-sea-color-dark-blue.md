# ADR-SRS-088: 標高地形図の海の色を濃い青にする

| 項目 | 内容 |
|---|---|
| 状態 | 採用・未実装 |
| 決定日 | 2026-11-23 |

---

## Context

[ADR-SRS-047](ADR-SRS-047-terrain-color-scheme-gist-earth-hillshade.md) は、標高地形図（[FR-015](../20_SRS.md#fr-015-標高地形図出力)）の標高 0m 以下の画素（海面・NODATA・人工ボーダー）を白 `#FFFFFF` で塗ると決めた。

白には、陸地の色と同じになりうる欠点がある。陸地の色は、gist_earth の 64〜255 行目の色（丸めで 63 行目もありうる。[ADR-SRS-047](ADR-SRS-047-terrain-color-scheme-gist-earth-hillshade.md) の正規化では標高が正の画素は 0.25 を超える）と明るさ 0〜1 を overlay で合成して決まる。明るさが 1 の画素で、色の 3 チャンネルがどれも 0.5 を超えると、合成の結果は白になる。システムテスト仕様書（ST）の `ST-FR-015-06` の孤立した最高点の画素がこれに当たり、設計どおりの実装では陸地が海と同じ白になることが、単体テスト仕様書（UT）のケースを足す材料集めで分かった。

海の色は、2026-07-06 までに、濃い青 `#1A4F72`（当時の C の実装の色）、水色 `#B7E5FA`、桜色 `#FFB7C5`、薄いピンク `#FFE4E9` を試し、薄紫 `#E6D9F5` を経て白に決めた（[調査資料](research/terrain-colormap-hillshade-research.md)）。濃い青をやめた理由の記録は無い。黒を試した記録は無い。

2026-11-23 に、実データの 4 つの範囲（5338・宮古島・伊豆諸島・千葉）で 6 色（白・黒・紺・濃い青・水色・灰色）を塗り比べ、陸地が取りうる色の全体（68,932 色）と候補の色との最も近い距離（各チャンネルの差の最大）を求めた。陸地の色は、gist_earth の 63〜255 行目（63 行目は、0.25 のすぐ上の値の丸めで当たりうる行）ごとに、8 ビットの値が切り替わる明るさの境目をすべて取り、境目・境目の前後・境目の間の値で合成して、8 ビットに切り捨てたものである。

## Decision

標高 0m 以下の画素を、濃い青 `#12407A` で塗る。[ADR-SRS-047](ADR-SRS-047-terrain-color-scheme-gist-earth-hillshade.md) の「海マスク」の色をこれに改める。カラーマップと陰影の対象外とすること、NODATA を海面と見分けないこと、ほかのパラメータは変えない。

- 理由 1（足切りの基準）: 陸地が取りうる色と同じにならない。`#12407A` と陸地の色の距離は 24 で、陸地の色の許容差（各チャンネル 1）より十分に大きい。この値は配色の計算から決まり、解析範囲によらない。
- 理由 2: 低い平野の水色と見分けられる。これは見本を見た目の判断である。
- 選んだ者: 持ち主が 2026-11-23 に選択を任せ、Claude（Opus 5.5）が選んだ。2026-07 の経緯を伝えた後、持ち主がこれでよいと確かめた。

## Alternatives

距離は、陸地が取りうる色との最も近い距離（各チャンネルの差の最大）。足切りに使い、順位には使わない。

| 案 | 距離 | 採らない理由 |
|---|---|---|
| 白 `#FFFFFF`（これまで） | 0 | 陸地と同じ色になりうる。図の余白・背景と紛れやすい |
| 黒 `#000000` | 0 | 陸地と同じ色になりうる（明るさ 0 で、3 チャンネルがどれも 0.5 以下の画素。宮古島の見本で 1 画素） |
| 薄いピンク `#FFE4E9` | 8 | 明るい画素と近い |
| 濃い青 `#1A4F72`（2026-07 に試した色） | 13 | `#12407A` より陸地の暗い青緑に近い |
| 紺 `#0B1E3F` | 14 | 暗い斜面と近い（差 20 以内の画素が千葉で 4,317。タイルの欠けた伊豆諸島では 14,339 で、目安） |
| 薄紫 `#E6D9F5` | 15 | 明るい画素と近い |
| 灰色 `#808080` | 42 | 海らしく見えない（目の判断） |
| 水色 `#B7E5FA` | 50 | 低い平野の水色と紛れる（目の判断） |
| 平野の水色も見直す | — | gist_earth と正規化の見直しになり、配色の全体が変わる。海の色を替えても変わらない見え方なので、今回は扱わない |

## Consequences

### Positive

- 海面と陸地が、どの解析範囲でも同じ色にならない。図の余白・背景とも紛れない。

### Negative

- 陸地の中の NODATA も濃い青になり、湖のように見えて、白よりも気づきにくいかもしれない（欠けを入れた見本では確かめていない。確かめないで進めると持ち主が 2026-11-23 に決めた）。湖は標高が 0m より高ければ陸地の色で描かれるので、内陸の濃い青は、欠けか 0m 以下の低地である。NODATA と海面を見分けられないことは、これまでと同じである（データの読み込みの大きな失敗は、[HLD 4.4.4](../30_HLD.md#444-設計判断) の DEC48・DEC49・DEC64 が機械的に止める）。
- サンプル画像と、UT・ST の海の画素の期待を作り直す。
