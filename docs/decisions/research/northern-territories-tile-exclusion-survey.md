# 北方領土タイル除外の実測調査

調査日: 2026-09-23

## データ

- N03-20260101.geojson（行政区域データ）
- 北方領土: N03_007 が 01695〜01700（ポリゴン 726 件）
- 本土: N03_001=北海道 のうち、上記以外のポリゴン

## 方法

現行 SRS の中心点判定（タイル中心がポリゴン内に含まれるかどうか）で Z15 の除外タイルを列挙し、Z14 は `(x // 2, y // 2)` で導いた。日本全土1次メッシュコードリストのうち、先頭2桁が64以上・末尾2桁が44以上のメッシュ（北方領土・北海道東部にあたる範囲）ごとに、除外されずに残ったタイルのうち、タイル矩形が北方領土ポリゴン・本土ポリゴンそれぞれと交差するものを数えた。

## 結果

中心点判定による除外タイルは Z15 で 6,502 枚、Z14 で 1,813 枚。ADR-URD-005 の交差ベースの検証では北方領土タイルは 7,321 枚とされているので、差の約 819 枚（中心が海側にずれた海岸タイル）が中心点判定では除外から漏れる。

中心点判定の除外タイルのうち、本土の陸地に交差するタイルは Z15・Z14 とも 0 枚だった（誤って本土タイルを除外するリスクは無い）。一方、除外されずに残ったタイル（下表）には、本来の意図どおり本土の陸地に交差するものが多数含まれる（6545・6546・6645 等）。

| メッシュ | 本土の陸地に交差する残りタイル | 北方領土に交差する残りタイル（Z15 / Z14） |
|---|---|---|
| 6646 | 0 | 154 / 46 |
| 6647 | 0 | 49 / 9 |
| 6747 | 0 | 187 / 47 |
| 6748 | 0 | 103 / 32 |
| 6847 | 0 | 25 / 7 |

上の 6646・6647・6747・6748・6847・6848 の 6 メッシュは、除外されずに残るタイルのうち本土の陸地に交差するものが 0 枚である。6545・6546・6645 は、北方領土に交差するタイルと本土の陸地に交差するタイルの両方を持つ。

## メッシュ単位の確認

日本全土1次メッシュコードリストの 175 メッシュのうち、メッシュ範囲（四隅の緯度経度による矩形）が北方領土以外の N03 ポリゴンと交差しないメッシュは、上の 6 件だけだった。この 6 件はいずれも北方領土のポリゴンとは交差する。N03 ポリゴンを 1 つも持たないメッシュ（純海域のメッシュ）は無かった。6 件のタイル被覆範囲は、いずれも本土ポリゴンと交差しない。

## 限界

- 配信状況の抜き取りは 6 枚のみ。全タイルの配信状況は確認していない。
- ローカルキャッシュは北海道東部のタイルを含んでおらず、実際の取得・解析との照合は行っていない。
- 除外から漏れた海岸断片からプロミネンス 150m 以上のピーク候補が実際に検出されるかは評価していない。
- 未整備（地理院側でタイルが提供されていない）によりタイルが全欠如するメッシュが本土側で起きるかどうかは確認していない。
