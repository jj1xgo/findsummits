# ADR-SRS-059: 標高タイルの取得完了をメッシュごとの記録で示す

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-02 |

## Context

[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) は、フェーズ2 の起動前提条件として「[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) による標高タイルのローカルキャッシュ取得完了」を求めている。ところが、取得完了を何で判定するかは SRS にも HLD にも無かった。

- [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) などの解析は、ローカルキャッシュに無いタイルを NODATA として扱う。取得が途中で止まったキャッシュでも解析は止まらず、結果が黙って悪くなる。[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) の異常系が、欠損タイルを残したまま正常終了しないと定めているのは、これを避けるためである。
- ローカルキャッシュのタイルを数えても、地理院側で未整備のために無いタイル（[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) の HTTP 404）と、取り損ねたタイルを見分けられない。

[HLD 3.1](../30_HLD.md#31-fr-001-標高タイル事前取得) の設計で、[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) が取得を最後まで終えた 1次メッシュを記録し、[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) がその記録を読むことにした。この記録は FR をまたいで受け渡す永続的な内部データなので、`docs/CLAUDE.md` の分類ルール（内部データは SRS §8 に記載する）に従い、[SRS §8.1](../20_SRS.md#81-内部データ一覧) に載せる。

## Decision

1. 内部データ「標高タイル取得完了記録」を [SRS §8.1](../20_SRS.md#81-内部データ一覧) に No.17 として追加する。内容は、取得を最後まで終えた 1次メッシュコードの集合とする。保存先は `$DATA_DIR/tiles/` の直下とし、ファイル名・形式・更新の手順は HLD で定める。
2. [FR-001](../20_SRS.md#fr-001-標高タイル事前取得) は、取得を最後まで終えたときに今回の対象の 1次メッシュを記録に残す。途中でエラー終了した実行の対象のメッシュは、記録に残さない。出力の表に記録を足す。
3. [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) は、フェーズ2 の起動前提条件「標高タイルのローカルキャッシュ取得完了」をこの記録で判定する。入力の表に記録を足す。検査の詳細は HLD で定める。

## Alternatives

**(A) 記録を作らず、ローカルキャッシュのディレクトリがあるかだけを見る**

却下。取得が途中で止まっても前提条件を満たしてしまう。

**(B) ローカルキャッシュのタイルを数えて判定する**

却下。未整備で無いタイルと、取り損ねたタイルを見分けられない。

**(C) 記録を HLD だけに置き、SRS には載せない**

却下。[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) が作って [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) が読む内部データが [SRS §8.1](../20_SRS.md#81-内部データ一覧) の一覧から漏れ、`docs/CLAUDE.md` の分類ルールと合わない。

## Consequences

- 反映先: [SRS FR-001](../20_SRS.md#fr-001-標高タイル事前取得)・[FR-023](../20_SRS.md#fr-023-解析パイプライン制御)・[§8.1](../20_SRS.md#81-内部データ一覧)、[HLD 3.1](../30_HLD.md#31-fr-001-標高タイル事前取得)・[2.4.4](../30_HLD.md#244-フェーズ指定)・[2.10.3](../30_HLD.md#2103-フェーズのやり直し)。
- 記録のファイル名・書式、`--mesh` を指定しない取得での記録の書き直し、N03 行政区域前処理（[FR-017](../20_SRS.md#fr-017-n03-行政区域前処理データ準備)）が出力を作り直すときに記録を消すことは、HLD で定める。
- [ST](../70_ST.md) の [FR-001](../20_SRS.md#fr-001-標高タイル事前取得)・[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) の試験に、記録を確かめるケースを足す。ST の改訂の機会に合わせる。
