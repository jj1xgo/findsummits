# ADR-SRS-064: DEM10b のタイルの欠けが多いメッシュでは解析を止める

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-03 |

## Context

[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) は、解析対象メッシュのタイルが 1 枚も無いときと、読めないタイルがあるとき（[ADR-SRS-061](ADR-SRS-061-stop-on-unreadable-elevation-tiles.md)）に処理を中止し、存在メッシュ内の部分的欠損は NODATA で続ける。

[FR-002](../20_SRS.md#fr-002-dem-階層フォールバック) の最後の段の DEM10b は、陸地の全域を覆う。DEM5a・5b・5c は航空レーザ測量の範囲だけで、山地などに NODATA の画素が多い。DEM10b のタイルがローカルキャッシュに無いと、DEM5 が NODATA の陸地がそのまま NODATA の穴になる。穴で分かれた陸地の成分は人工ボーダーに届かず、[FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) の海面確定規則で Key コルが海面になり、プロミネンスがピークの標高になる。この誤りは出力からは見分けられない。

動作確認環境のローカルキャッシュで測った（[調査資料](research/nodata-gaps-in-land-survey.md)、2026-10-03）。

- メッシュ 5539 は、DEM5 のタイルがある 7,071 の位置のうち 6,964（98.487%）で DEM10b のタイルが無かった。取得の記録では DEM10b の 1,794 枚すべてが「存在なし」だったが、提供元には実在した。DEM5 が NODATA の山地が穴になり、最高点 1,660.93m の陸地を含む 854 片が穴で分かれていた。
- ほかの 12 メッシュでは、この割合は 0〜0.204% だった。0 でない位置は、東京湾の埋立地など DEM10b より新しい陸地だった。

[ADR-SRS-019](ADR-SRS-019-land-summit-highest-peak-handling.md) の Consequences の 1 は、NODATA で海面確定規則が誤って働くリスクを、タイルが 1 枚も無いメッシュで止めることで抑えるとした。この場面では DEM5 のタイルがあるので、その停止では止まらない。[ADR-SRS-061](ADR-SRS-061-stop-on-unreadable-elevation-tiles.md) は、取得の記録の後でキャッシュから消えたタイルを検出しないとしており、取得で漏れたタイルも同じく見分けられない。

## Decision

1. [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) は、解析対象メッシュのいずれかについて、DEM5a・DEM5b・DEM5c のどれかのタイルがある位置のうち DEM10b のタイルが無い位置の割合がしきい値を超えるとき、エラーを出力して処理を中止する。該当メッシュコードを示し、タイル事前取得（[FR-001](../20_SRS.md#fr-001-標高タイル事前取得)）の再実行を促す。
2. しきい値と数え方の詳細は HLD で定める。

## Alternatives

**(A) 警告を出して続行する**

却下。全国の実行では警告が埋もれやすく、見落とすと申請用の結果が黙って変わる（[ADR-SRS-061](ADR-SRS-061-stop-on-unreadable-elevation-tiles.md) の (A) と同じ理由。持ち主の判断、2026-10-03）。

**(B) DEM10b のタイルが無い位置が 1 か所でもあれば中止し、正当な位置を許可リストで通す**

却下。DEM10b より新しい陸地（埋立地など）は正当に食い違うので、許可リストの保守と設定項目が増える（持ち主の判断、2026-10-03）。

**(C) [FR-006](../20_SRS.md#fr-006-コル検出プロミネンス計算) で、高い標高の画素で NODATA に接した成分を未確定にする**

却下。海に面した崖の島も未確定になりうる（持ち主の判断、2026-10-03）。

## Consequences

- 反映先: [SRS FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の異常系、[HLD 3.4](../30_HLD.md#34-fr-004-33メッシュ結合解析オーケストレーション)・[3.14](../30_HLD.md#314-fr-014-広域結合解析オーケストレーション)・[2.5.3](../30_HLD.md#253-利用者向けのメッセージ)。
- DEM5 のタイルが無い位置（DEM5 が 0 枚のメッシュを含む）の DEM10b の欠けは、この検査で見つけられない。
- しきい値は動作確認環境の 13 メッシュで決めた。全国の取得の後に、全メッシュの割合を確かめる（[HLD 3.4.5](../30_HLD.md#345-未決事項と後続)）。
- [ST](../70_ST.md) の [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の試験に、DEM10b のタイルの欠けがしきい値を超えるメッシュと超えないメッシュのケースを足す。ST の改訂の機会に合わせる。
- 現行のプロトタイプとの違いは、C4 の C++ 移行（[ADR-SRS-010](ADR-SRS-010-cpp-opencv-migration.md)）の段で反映する。
