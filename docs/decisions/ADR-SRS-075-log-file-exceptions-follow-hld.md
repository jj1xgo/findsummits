# ADR-SRS-075: ログファイルを作らない場面を、ログファイルを開くまでの準備で異常終了する場合に広げる

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-11 |

---

## Context

ソフトウェア要件仕様書（SRS）の [NFR-007](../20_SRS.md#nfr-007-ログ出力) は、エラー・警告を標準エラー出力とログディレクトリに同時に出し、ログファイルを作らずに標準エラー出力だけに出す例外を「起動直後の設定・引数の検査で異常終了する場合」だけにしていた（[ADR-SRS-058](ADR-SRS-058-error-messages-to-stderr.md) の Decision 3）。

概要設計（HLD）は、ログファイルを開く時機を「設定と引数の検査を終えた後、利用者向けの 3 コマンドはロックを掛けた後」と決め（[HLD 5.7.2](../30_HLD.md#572-処理の流れ) の 1「ログファイルを開く」）、それより前に異常終了する次の場面でもログファイルを作らない。

- 同じデータを使う別のコマンドが動いているため止まるとき、ロックファイルを開けないとき（[HLD 2.9.3](../30_HLD.md#293-同時起動の排他)、[2.5.3](../30_HLD.md#253-利用者向けのメッセージ)）。
- ログの出力先を用意できないとき（ログディレクトリを作れないか、ログファイルを開けない。[HLD 2.3.2](../30_HLD.md#232-設定ファイル)、[2.5.3](../30_HLD.md#253-利用者向けのメッセージ)）。
- パイプライン制御（CMP3）で、設定解決の出力が決まった形でないとき（ログの出力先を用意する前に起きる。[HLD 2.5.3](../30_HLD.md#253-利用者向けのメッセージ)）。

どれも、ログファイルを開く前か、開こうとして失敗した場面である。HLD の決定は変えず、SRS をこれに合わせる。[HLD 5.7](../30_HLD.md#57-nfr-007-ログ出力) の多視点のレビュー（2026-10-09）で見つかり、持ち主の判断で 5.7 の手直しとは分けて後続にしていた。

## Decision

1. [NFR-007](../20_SRS.md#nfr-007-ログ出力) の出力先の項目の例外を、「ログファイルを開くまでの準備（設定・引数の検査、別のコマンドが同じデータを使って動いていないかの確かめ、ログの出力先の用意）で異常終了する場合」に改める。この場合はログファイルを作らず、標準エラー出力だけに出す。正常に終わる場合（使い方の表示など）は、この例外に入れない。
2. 場面の細部（どの検査の順で、どのメッセージを出すか）は HLD に置き、SRS には写さない。SRS は HLD の語（同時起動、排他、ロック）を持ち込まず、要件の語で書く。
3. [ADR-SRS-058](ADR-SRS-058-error-messages-to-stderr.md) の本文は書き換えず、状態と決定日の表の直後に注を置く。

## Alternatives

- **(a) SRS を変えず、HLD を SRS に合わせる**: 別のコマンドが動いているため止まるときにもログファイルを作ると、そのコマンドが書いている最中のログの置き場に、止まった側がファイルを作ることになる。ロックを掛けた後でログファイルを開くという HLD の決定（DEC174「ログはロックを掛けた後で開く」）を崩す。
- **(b) HLD の場面をすべて SRS に列挙する**: 実装の細部を SRS に写すことになり、HLD を直すたびに SRS の追従が要る。
- **(c) 「ログファイルを開く前に止まる場合」とだけ書く**: いつ開くかを決めない限りどんな設計でも満たし、正常終了も含めて読める。準備の中身を挙げて上限にした。

## Consequences

- [NFR-007](../20_SRS.md#nfr-007-ログ出力) の出力先の項目を直し、[ADR-SRS-058](ADR-SRS-058-error-messages-to-stderr.md) に注を置いた。[HLD 5.7.5](../30_HLD.md#575-未決事項と後続) の 5「SRS の追従」を決めた形に縮め、[HLD 2.5.3](../30_HLD.md#253-利用者向けのメッセージ) から本 ADR を指した。
- システムテスト（ST）の `ST-NFR-007-01` の追従は、この改訂に含めず、ST の改訂の機会に扱う（[ADR-SRS-073](ADR-SRS-073-align-srs-wording-with-hld-decisions.md) の Decision 5 と同じ扱い）。[HLD 5.7.5](../30_HLD.md#575-未決事項と後続) の 4「ST の追従」が挙げる場面（同時起動・ロックファイルを開けない・終了コード 2）に、ログの出力先を用意できないときと、CMP3 で設定解決の出力が決まった形でないときも加えて確かめる。
- ログファイルを開いた後にログに書けなくなったときの扱い（[HLD 5.7](../30_HLD.md#57-nfr-007-ログ出力) の DEC177「ログに書けなければ止まる」）は、この改訂の範囲外とした。
