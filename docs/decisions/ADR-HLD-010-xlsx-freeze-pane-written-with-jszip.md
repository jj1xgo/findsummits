# ADR-HLD-010: 申請書のウィンドウ枠の固定は、SheetJS CE で書いた後に JSZip で書き足す

| 項目 | 内容 |
|---|---|
| 状態 | 採用・未実装 |
| 決定日 | 2026-11-10 |

---

## Context

申請書生成 UI（CMP7）は、申請書と一覧の XLSX をブラウザで書く。ライブラリは Leaflet・SheetJS・JSZip の 3 つに限っている（[HLD](../30_HLD.md) の [DEC129](../30_HLD.md#4134-設計判断)「ライブラリは 3 つに限り、版を固定して CDN から取る」、[SRS §3.4](../20_SRS.md#34-外部システム依存関係環境)）。申請書は、様式と同じ見出しの結合と、`A6` でのウィンドウ枠の固定を持つ（[DEC117](../30_HLD.md#4114-設計判断)「申請書はテンプレートの配置を再現する」）。持ち主は、SheetJS の有償版を使わず、無償版で書けないものがあれば無償のほかの方式にすると決めていた（2026-11-08）。

2026-11-08〜11-10 に、無償の 4 つの方式で申請書と一覧の見本を書き、openpyxl で読み返した（[#197 の調査の記録](research/library-file-scheme-probe.md)）。

- (a) SheetJS CE 0.20.3: 結合・値と型・表示形式は書けるが、`A6` での固定を書けない
- (b) (a) で書いた後に、JSZip 3.10.2 で `xl/worksheets/sheet1.xml` の `<sheetView>` に `<pane>` を書き足す: 要件を全部満たし、同じ入力から同じバイト列になる（JSZip の書き戻しで、元のエントリの時刻を渡し、フォルダのエントリを足さないとき）
- (c) ExcelJS 4.4.0: 要件を全部満たすが、文書のプロパティの作成日時と更新日時と、XLSX の中の ZIP のエントリの時刻に今の時刻を入れる
- (d) xlsx-js-style 1.2.0: `A6` での固定を書けない

## Decision

1. **方式**。申請書と一覧は SheetJS CE 0.20.3 で書く。申請書の `A6` での固定は、SheetJS CE で書いたバイト列を JSZip で開き、`<sheetView>` に `<pane>` を書き足して書き直す。書き直しでは、書き直したエントリの時刻を元のエントリの時刻のままにし、JSZip がフォルダのエントリを足さないようにし、DEFLATE で圧縮する（時刻を渡さないか、フォルダのエントリを足すと、エクスポートの時刻が入って決定性が崩れる）。HLD の DEC117 と 4.11.2 にこの書き方を書く（持ち主の判断、2026-11-10）。
2. **ライブラリの名前**。DEC129 の 3 つのライブラリは変えない。SRS・HLD・LLD・結合テスト仕様書（IT）・システムテスト仕様書（ST）の SheetJS の名前は書き直さない。
3. **セルの書式**。SheetJS CE はセルの書式を書けないので、見出しの折り返しなどのセルの書式は書かない（HLD 4.11.1 の対象外の「見出しの書式を様式に合わせるか」のとおりで、要件ではない）。

## Alternatives

- (c) ExcelJS に替える: 折り返しも書けるが、[NFR-003](../20_SRS.md#nfr-003-再現性決定論的出力) の決定性のために、作成日時と ZIP の時刻を書き直す処理が要る。ライブラリを替えるので、SRS の 12 か所と HLD・LLD・IT・ST の名前の書き直しと、SRS の改訂の ADR が要る。却下（持ち主の判断、2026-11-10）。
- (a) SheetJS CE だけで書き、固定を諦める: 様式の配置から外れ、DEC117 を変えることになる。却下。
- (d) xlsx-js-style に替える: 固定を書けず、2022-04 から更新が無い。却下。
- SheetJS の有償版を使う: 有償版は使わない（持ち主の判断、2026-11-08）。却下。

## Consequences

- CMP7 は、SheetJS CE の出力の XML を一部だけ書き直す処理を自分で持つ。SheetJS CE の版を上げるときは、`<sheetView>` の形が変わっていないかも確かめる（[DEC12](../30_HLD.md#266-設計判断)「安定した最新の版に追従する」）。確かめの道具は `research/library-file-scheme-probe/` に置いた。
- 申請書の生成も JSZip に依存するので、ソフトウェア要件仕様書（SRS）の [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) の入力と異常系に JSZip を足した（[ADR-SRS-087](ADR-SRS-087-application-xlsx-also-uses-jszip.md)）。
- 書き直す処理の関数の分け方と試験は、詳細設計書（LLD）で決める。
