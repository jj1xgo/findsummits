# ADR-URD-022: UR-006 を目視確認用 GeoJSON・作業用ビューア・公開用ビューアの 3 件に分割し、UR-004・UR-005 は分割しない

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-08 |

> ※ 本 ADR の Decision 2 が写した [UR-018](../10_URD.md#ur-018) の「公開用の静的 HTML ビューア（閲覧専用）を生成できること」は、[ADR-URD-023](ADR-URD-023-ur-018-publish-wording.md) で、「…公開できること」と改めた（2026-10-09）。公開用ビューアは、ツールが生成するものではなく、静的ホスティングが配信するものであるため。

---

## Context

[ADR-OPS-002](ADR-OPS-002-reference-standards-and-intended-deviations.md) で、要求の文書は ISO/IEC/IEEE 29148:2018 を参照すると決めた。29148:2018 は、1 件の要求が 1 つのことだけを述べること（singular）を、良い要求の特性に挙げているとされる（規格の本文でも、出典を記録した資料でも確かめていない）。[URD §4](../10_URD.md#4-ユーザーニーズ) のうち、[UR-004](../10_URD.md#ur-004)（申請書 XLSX）、[UR-005](../10_URD.md#ur-005)（サミット一覧 XLSX）、UR-006（目視確認用 GeoJSON と HTML ビューア）は、1 件の中に複数の事柄を含む。

UR-006 は、目視確認用 GeoJSON、作業用ビューア（ローカルで開く。山岳名入力・XLSX エクスポート）、公開用ビューア（閲覧専用。静的ホスティング、リリース版と開発版の同時公開と判別）の 3 つの成果物を 1 件にまとめていた。SRS の FR/NFR のうち UR-006 を「対応 UR」に持つものも、GeoJSON を作るもの、作業用ビューア、公開用ビューアに分かれていた。[URD 3.1](../10_URD.md#31-ステークホルダー) では、公開用ビューアで申請の中身を確かめ、リリース版か開発版かを見分けるのは SOTA 日本支部マネージャである。1 件のままでは、公開用ビューアの要求を作業用ビューアと分けて追跡できない。

## Decision

1. **分割する基準**: 1 件の UR が、成果物の異なる複数の要求を含み、それぞれを実現する FR/NFR の集合が違うときに分割する。1 つの成果物に中身や条件が付いているだけのものは分割しない。
2. **UR-006 を分割する**: UR-006 の文言を成果物ごとに分け、次の 3 件にする。文言は UR-006 から写し、意味は変えない（足したのは、成果物ごとに主語をそろえるための語だけ）。
   - [UR-016](../10_URD.md#ur-016): 目視確認用 GeoJSON を生成できること
   - [UR-017](../10_URD.md#ur-017): 国土地理院地図・OSM・OpenTopoMap を切り替え可能な、作業用の静的 HTML ビューア（ローカルで開く。山岳名入力・XLSX エクスポート機能付き）を生成できること
   - [UR-018](../10_URD.md#ur-018): 国土地理院地図・OSM・OpenTopoMap を切り替え可能な、公開用の静的 HTML ビューア（閲覧専用）を生成できること。公開用ビューアは、申請エビデンスの GeoJSON をそのまま表示するものを静的ホスティングで公開でき、リリース版と開発版を同時に公開でき、閲覧者がどちらかを判別できること
3. **番号**: 新しい番号を振り、UR-006 は欠番にする（UR-009 と同じ扱い。[ADR-URD-020](ADR-URD-020-requirement-traceability-and-consistency.md)）。UR-006 の番号を 3 件のどれかに残すと、過去の記録の UR-006 が今と違う範囲を指す。UR-006a のような子の番号は、`tools/lint_trace.py` の ID の書式を変えることになる。欠番は `tools/lint_trace.py` の `RETIRED_IDS` に本 ADR と一緒に書く。
4. **分割しない UR**: [UR-004](../10_URD.md#ur-004) は、申請書 XLSX を作る 1 つの要求に、生成する行の種類の条件が付いたものである。[UR-005](../10_URD.md#ur-005) は、サミット一覧 XLSX を作って申請エビデンス ZIP に同梱する 1 つの要求に、中身の条件が付いたものである。どちらも成果物は 1 つで、1 の基準に当たらない。分けると条件だけの UR ができる。これは本プロジェクトの判断で、29148:2018 に照らした評価は Consequences のとおり保留する。
5. **追跡の付け替え**: SRS の「対応 UR」の宣言を、各 FR/NFR が実現する成果物に合わせて次のとおり付け替える。今の UR-006 の追跡を分けるだけで、新しい追跡は足さない。SRS §12 と ST §5 の表、URD 3.1 と 3.3、HLD の参照もこれに合わせる。

   | FR/NFR | 新しい対応 UR |
   |---|---|
   | [FR-009](../20_SRS.md#fr-009-sotaリスト突合match_status-判定) | [UR-016](../10_URD.md#ur-016) |
   | [FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成) | [UR-016](../10_URD.md#ur-016) |
   | [FR-018](../20_SRS.md#fr-018-per-mesh-ピーク候補-geojson-統合) | [UR-016](../10_URD.md#ur-016) |
   | [FR-013](../20_SRS.md#fr-013-html-ビューア生成) | [UR-017](../10_URD.md#ur-017) |
   | [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) | [UR-017](../10_URD.md#ur-017) |
   | [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) | [UR-018](../10_URD.md#ur-018) |
   | [FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) | [UR-018](../10_URD.md#ur-018)（公開用データの供給。UR-006 のときと同じ限定） |

6. **過去の ADR の記述**: 既存の ADR の UR-006 への言及は、決定の時点の記録として UR-006 のまま残し、アンカーが無くなるリンクだけを外す。

## Alternatives

- **3 件とも分割する**: 29148:2018 の singular に字面でそろう。ただ、[UR-004](../10_URD.md#ur-004)・[UR-005](../10_URD.md#ur-005) を分けると条件だけの UR ができ、追跡の行が増えるわりに得るものが少ない。却下。
- **どれも分割せず、例外として [ADR-OPS-002](ADR-OPS-002-reference-standards-and-intended-deviations.md) の表に足す**: 直す量は最小だが、公開用ビューアの要求を作業用ビューアと分けて追跡できないままになる。却下。
- **UR-006 を作業用（GeoJSON を含む）と公開用の 2 件に分ける**: 目視確認用 GeoJSON を作る FR（[FR-009](../20_SRS.md#fr-009-sotaリスト突合match_status-判定)・[FR-016](../20_SRS.md#fr-016-ピーク域ポリゴン生成)・[FR-018](../20_SRS.md#fr-018-per-mesh-ピーク候補-geojson-統合)）は、作業用ビューアの FR と集合が違い、作業用ビューアの UR に入れると 1 の基準に当たる UR がまた 1 件できる。却下。
- **UR-006 の番号を 3 件のどれかに残す**: Decision 3 のとおり、過去の記録の UR-006 が今と違う範囲を指す。却下。

## Consequences

- [URD §4](../10_URD.md#4-ユーザーニーズ) に [UR-016](../10_URD.md#ur-016)〜[UR-018](../10_URD.md#ur-018) を足し、UR-006 の行を消して注記を置いた。URD は確定済みのため、SRS → HLD のフェーズゲートの記録に補足を追記する（[開発ガイド §4](../03_development.md#4-フェーズゲート)）。
- `tools/lint_trace.py` の `RETIRED_IDS` に UR-006 を足した。
- 29148:2018 の本文で確かめていない点（singular の定義と適用の範囲）と、[UR-004](../10_URD.md#ur-004)・[UR-005](../10_URD.md#ur-005) を分割しないことが規格と違う形にあたるかは、[ADR-OPS-002](ADR-OPS-002-reference-standards-and-intended-deviations.md) の Decision 4 に従い保留する。
- ほかの UR（[UR-001](../10_URD.md#ur-001)・[UR-013](../10_URD.md#ur-013)・[UR-015](../10_URD.md#ur-015) など）も複数の事柄を含みうるが、Decision 1 の基準で見直すことは本 ADR の範囲に含めない。
