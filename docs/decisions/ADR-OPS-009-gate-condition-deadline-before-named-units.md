# ADR-OPS-009: 条件付きGo の条件の期限に、指定した単位に入る前を足す

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-19 |

---

## Context

[開発ガイド §4](../03_development.md#4-フェーズゲート) の条件付きGo の条件は、期限を次のステージの作業の節目で決める。節目は、[ADR-OPS-006](ADR-OPS-006-conditional-go-deadlines-and-gate-re-review.md) の Decision 1 で「次のステージのどの作業の単位にも入る前」か「指定した単位が確定するまで」のどちらかに限っていた。

ゲート 3（概要設計（HLD）→ 詳細設計（LLD））の判定の後、2026-10-19 に、SOTA に未反映の申請を突合の 2 つめの入力にする要求の変更（[ADR-URD-029](ADR-URD-029-pending-applications-in-matching.md)）が入り、再審査を要すると承認者が判断した。この変更の追従（ソフトウェア要件仕様書（SRS）・HLD・テスト文書）が要るのは、その追従を入力にする LLD の節（突合、申請書生成 UI、公開用ビューアの章）を書き始めるときである。ところが LLD は、共通部品と横断の節（2.1〜2.4）をすでに書き始めている。

- 「どの単位にも入る前」は、すでに過ぎているので使えない。
- 「指定した単位が確定するまで」は、指定した単位の書き始めを止めない。追従が済む前に、追従を入力にする節を書き始められるので、書いた後に HLD が変わる手戻りを防げない。開発ガイド §4 の「期限がその条件の要る時点より遅くないか」にも反する。
- 次のステージ全体を止める No-Go にすると、この変更の影響を受けない節の作業まで止まる。

ADR-OPS-006 の Decision 1 は、「最初の単位」を期限にしない理由を、どの単位から書き始めるかで期限に掛からなくなり、最初に書く単位が先に決まらないこともあるためとしていた。単位を名指しする形なら、名指しした単位のどれから書き始めても掛かるので、この理由に当たらない。

## Decision

1. **期限の節目に 3 つめの形を足す**: 「指定した単位に入る前」を足す。単位は名指しする。章で名指ししたときは、後からその章に足される単位も含む。「次のステージのどの作業の単位にも入る前」は、名指しする単位を全部にした場合として、今の字句のまま残す。名指しした単位を分割・統合・改名したときは、その後の単位も名指しに含む。
2. **止める範囲**: 名指しした単位のどれかに入る前に、条件を消化する。名指ししなかった単位は止めない。名指しできるのは、判定の時点でまだ入っていない単位に限る（すでに入った単位を名指しすると、期限がその時点で過ぎている）。章で名指しするとき、その章にすでに入った単位があれば、その単位を名指しから除き、除いた単位を記録に書く（その章を名指しできないとすると、後から足される単位まで止められなくなり、止める目的に合わない）。
3. **止め方は運用に任せる**: どの課題にどう印を付けるか、書き始める前に何を確かめるかは、メンテナの運用で定める（[ADR-OPS-006](ADR-OPS-006-conditional-go-deadlines-and-gate-re-review.md) の Decision 8）。
4. **延長**: 数え方は今の §4 のままにする。節目を後ろの作業に替えるのは延長に数え、条件ごとに 1 回だけとする。名指しする単位を変えるのは節目を替えることなので、§4 のとおり再審査による。そのうち、単位を増やすのは前倒しなので延長に数えず、単位を外すか、後ろの単位に替えるのは延長に数える。名指しした単位を分割・統合・改名しただけで、名指しの範囲が変わらないときは、節目を替えることに当たらない。
5. **早さの審査**: 遅い単位だけを名指しすると、条件を付けない Go に近づく（ADR-OPS-006 の Decision 2 が、「確定するまで」の形について指摘した弱さと同じ）。記録の期限の根拠に、その条件を要る単位の一覧を書き、承認者は §4 の早さの審査で、名指しした単位がそれをすべて含むかを確かめる。

## Alternatives

- **今の 2 つの形から選ぶ**: 「どの単位にも入る前」は過ぎていて使えない。「確定するまで」は、追従を入力にする節の書き始めを止めず、期限がその条件の要る時点より遅くなる。不採用。
- **No-Go にして、追従を終えてから再審査する**: HLD を差し戻して直すものは無く、この変更の影響を受けない節の作業まで止まる。不採用。
- **「どの単位にも入る前」の字句を読み広げて、名指しした単位に使う**: 字句と食い違い、読み手が全体を止める形だと取り違える。別の形として書く。不採用。

## Consequences

- [開発ガイド §4](../03_development.md#4-フェーズゲート) の「期限」の箇条を、3 つの形を並べる文に直す。
- ADR-OPS-006 の Decision 1 に、この ADR で形を足したことの注記を足す。
- メンテナ個人の補足資料（`AGENTS.md`「個人運用の補足」）を、この形の止め方に合わせて直す。
- [用語集](../00_GLOSSARY.md#adr-命名規約)の「次の OPS」の番号を直す。
