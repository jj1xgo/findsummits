# ADR-SRS-061: 読めない標高タイルでは解析を止める

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-03 |

## Context

[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) は、ローカルキャッシュに無いタイルを NODATA として扱い、解析対象メッシュのタイルが 1 枚も無いときだけ処理を中止する。ローカルキャッシュにタイルのファイルがあっても標高タイルとして読めないとき（壊れた PNG、PNG でない中身、8 ビットの RGB でない画像、大きさの違う画像）の扱いは、SRS に無かった。

- 現行のプロトタイプは、読めないタイルを黙って NODATA にする。動作確認環境のローカルキャッシュには、取得で HTTP 404 の本文（XML）を保存した PNG でないファイルが 20 件あった（2026-10-02 に確認）。
- 読めないタイルを NODATA にすると、取得が途中で止まったときと同じく、結果が検出できない形で悪くなる。[ADR-SRS-059](ADR-SRS-059-tile-fetch-completion-record.md) が標高タイル取得完了記録を設けたのは、これを避けるためである。
- 提供元が HTTP 200 で壊れた中身を返したタイルは、[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) が中身を確かめないので、次の取得でも、更新の有無の問い合わせで「変更なし」が返る限り取り直されない。

あわせて、[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) の異常系の「解析対象メッシュ（…）のローカルキャッシュタイルが 1 枚も存在しない場合」は、窓全体で 1 枚も無いときとも、どれかのメッシュで 1 枚も無いときとも読めた。[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の異常系は、ウィンドウの中の存在メッシュのどれかにタイルが 1 枚も無ければ処理を中止するとしている。

[HLD 4.4](../30_HLD.md#44-fr-004-33メッシュ結合解析オーケストレーション) の設計で、この 2 点を決めた。

## Decision

1. [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) は、ローカルキャッシュのタイルのファイルを標高タイルとして読めないとき、NODATA として続行せず、エラーを出力して処理を中止する。読めなかったタイルを示し、そのファイルを削除してからタイル事前取得（[FR-001](../20_SRS.md#fr-001-標高タイル事前取得)）を再実行するよう促す。読めるかの判定の詳細と、いつ止めるか（窓のタイルを読み終えてから、まとめて示す）は HLD で定める。
2. [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) の「ローカルキャッシュタイルが 1 枚も存在しない」の判定は、解析対象メッシュごとに行う（[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の異常系と同じ）。該当メッシュコードを表示する。

## Alternatives

**(A) 警告を出して NODATA で続行する**

却下。全国の実行では警告が埋もれやすく、見落とすと申請用の結果が黙って変わる（持ち主の判断、2026-10-03）。

**(B) 黙って NODATA にする（現行のプロトタイプの形）**

却下。結果が検出できない形で悪くなる（持ち主の判断、2026-10-03）。

**(C) 「1 枚も存在しない」を窓全体で判定する**

却下。隣のメッシュのタイルが丸ごと欠けても続行し、海面確定規則の誤発動を防げない（持ち主の判断、2026-10-03）。

## Consequences

- 反映先: [SRS FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の異常系、[HLD 4.4](../30_HLD.md#44-fr-004-33メッシュ結合解析オーケストレーション)・[2.5.3](../30_HLD.md#253-利用者向けのメッセージ)。
- 標高タイル取得完了記録の後でローカルキャッシュから消えたタイルは、メッシュのタイルがすべて消えたときを除いて検出しない（[HLD 4.4.5](../30_HLD.md#445-未決事項と後続)）。
- [ST](../70_ST.md) の [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション)・[FR-014](../20_SRS.md#fr-014-広域結合解析オーケストレーション) の試験に、読めないタイルのケースと、窓の中の 1 つのメッシュだけタイルが 1 枚も無いケースを足す。ST の改訂の機会に合わせる。
- 現行のプロトタイプとの違いは、C4 の C++ 移行（[ADR-SRS-010](ADR-SRS-010-cpp-opencv-migration.md)）の段で反映する。北方領土除外メッシュの扱い（[ADR-SRS-053](ADR-SRS-053-northern-territories-tile-intersection-and-excluded-meshes.md)）は変えない。
