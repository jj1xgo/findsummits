# ADR-URD-027: UR-014 の「目視確認用 HTML ビューア」を作業用・公開用のビューアに改める

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-12 |

---

## Context

2026-10-12 に、改訂した多視点のレビュー（spec-panel）で URD の全体を見直した（[#204](https://github.com/jj1xgo/findsummits/issues/204)）。

[UR-014](../10_URD.md#ur-014) は「目視確認用 HTML ビューアは、表示するマーカーが多い場合でも、…動作すること」と書く。「目視確認用 HTML ビューア」は、UR-006（目視確認用 GeoJSON と HTML ビューア）の呼び名である。UR-006 は [ADR-URD-022](ADR-URD-022-split-ur-006-into-geojson-and-two-viewers.md) で、[UR-016](../10_URD.md#ur-016)（目視確認用 GeoJSON）・[UR-017](../10_URD.md#ur-017)（作業用ビューア）・[UR-018](../10_URD.md#ur-018)（公開用ビューア）に分けたが、[UR-014](../10_URD.md#ur-014) の呼び名はそのとき改めなかった。

いまのビューアは作業用と公開用の 2 つで、[用語集](../00_GLOSSARY.md)にも「作業用ビューア」「公開用ビューア」の項はあるが、「目視確認用 HTML ビューア」の項は無い。[UR-014](../10_URD.md#ur-014) を受ける [SRS NFR-010](../20_SRS.md#nfr-010-描画応答性連続操作の滑らかさ) は、作業用（[FR-013](../20_SRS.md#fr-013-html-ビューア生成)）と公開用（[FR-020](../20_SRS.md#fr-020-公開用ビューア配信)）の両方のマーカー描画に当てている。[UR-014](../10_URD.md#ur-014) の根拠の [ADR-URD-017](ADR-URD-017-viewer-marker-rendering-performance.md) は、ビューアの種類を分けずに「HTML ビューア」と書いていた。

## Decision

[UR-014](../10_URD.md#ur-014) の主語「目視確認用 HTML ビューア」を「作業用・公開用の HTML ビューア（[UR-017](../10_URD.md#ur-017)・[UR-018](../10_URD.md#ur-018)）」に改める。要求の範囲は変えない（[NFR-010](../20_SRS.md#nfr-010-描画応答性連続操作の滑らかさ) が当てている範囲を、URD の字句で示すだけである）。ほかの字句と、SRS の「対応 UR」の追跡は変えない。確定済みの URD の補足として、URD に注記を置く。

## Alternatives

- **(a) 今のままにする**: 用語集に無い呼び名が残り、[UR-014](../10_URD.md#ur-014) が公開用ビューアに当たるかを、[NFR-010](../20_SRS.md#nfr-010-描画応答性連続操作の滑らかさ) を読むまで判断できない。
- **(b) 「HTML ビューア」とだけ書く**: 短いが、どのビューアを指すかを [UR-017](../10_URD.md#ur-017)・[UR-018](../10_URD.md#ur-018) へたどれない。

## Consequences

- URD の [UR-014](../10_URD.md#ur-014) の文言を直し、§4 に注記を置いた。
- SRS・概要設計書（HLD）・ST の文面は、[UR-014](../10_URD.md#ur-014) の呼び名を引いていないので直さない。ツールの振る舞いは変わらない。
