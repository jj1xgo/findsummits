# ADR-SRS-074: 公開用ビューアの閲覧の範囲・版ごとの URL・組み立てが止まったときの扱いを SRS に書く

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-11 |

## Context

ソフトウェア要件仕様書（SRS）の [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) と [§6.2.7](../20_SRS.md#627-公開用ビューア閲覧専用静的ホスティング配信) は、配信サービス・URL 構成・組み立て手順を概要設計（HLD）に委ねていた。2026-10-11 に、HLD 4.20 の未決事項「組み立てを動かす仕組み」を Cloudflare の公式資料で確かめ、Cloudflare Workers Builds で動かすと決めた。その際、HLD に委ねていた中に、閲覧者や利用者から見える振る舞いがあり、SRS の他の項目と同じ水準で書くべきだと持ち主が判断した。次の 4 点である。

- 開発版もログインなしで公開することは、HLD の DEC164 にだけ書かれ、SRS からは読み取れなかった。
- [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) は判別手段に URL を挙げるが、URL が配信のたびに変わらないことを求めていなかった。閲覧者に一度伝えた URL で見続けられることが要る。
- 組み立てが止まったときに前の版を配信し続けることは、閲覧者から見える異常時の振る舞いで、[FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の異常系の他の項目と同じ水準にある。
- [NFR-007](../20_SRS.md#nfr-007-ログ出力) は「すべてのバッチ処理」にログファイルを求める。配信の組み立ては設定ファイルを読まず `log_dir` を持たない。組み立ての環境に書いたファイルを外に残す仕組みは、今回の Cloudflare の資料調査では確認できなかった。HLD はログファイルの保存と取り出しの経路を設けない。対象に含めるかを SRS で明らかにしないと、HLD がこの要求に反して読める。

## Decision

1. [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の説明に、リリース版も開発版もログインなしで誰でも閲覧できること、版ごとに配信のたびに変わらない URL を 1 つずつ持つことを書く。[§6.2.7](../20_SRS.md#627-公開用ビューア閲覧専用静的ホスティング配信) の「用途」と「URL 構成」も同じ意味にする。URL の形は HLD に置く。
2. [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の異常系に、配信する物の組み立てが止まった場合は、止まった版を配信せず、前に配信していた版があればそれを配信し続け、無ければ何も配信しないことを書く。止める条件は HLD に置く。
3. [NFR-007](../20_SRS.md#nfr-007-ログ出力) に、公開用ビューアの組み立てはバッチ処理に含めないことを書く。組み立てのメッセージの出し先は HLD に置く。
4. 配信サービスの名前（Cloudflare Workers）と組み立ての仕組み（Workers Builds）は、引き続き HLD に置き、SRS に書かない。

## Alternatives

- SRS を変えず HLD にだけ書く案。SRS の記述規約では実装方式を HLD に委ねるが、上の 4 点は実装方式ではなく、閲覧者と利用者から見える振る舞いである。システムテスト（ST）の合否の根拠が HLD だけになる。
- 組み立てを [NFR-007](../20_SRS.md#nfr-007-ログ出力) の対象に含め、ログファイルを書かせる案。組み立ては `log_dir` を持たず、書いたファイルを組み立ての環境の外に残す仕組みを、今回の資料調査では確認できなかった。
- 開発版をログインの後に見せる案は、HLD の DEC164 で却下済み（得るものが小さく、閲覧者に開発版を見せられなくなる）。

## Consequences

- HLD 4.20 の DEC164「公開用は Cloudflare Workers で配信する」・DEC184「組み立ては Workers Builds で動かす」・DEC186「組み立てのメッセージは標準エラー出力だけ」が、本 ADR の SRS の文を満たす形になる。
- ST の追従（[FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の、版ごとの URL が配信の後も変わらないこと、ログインなしで開けること、組み立てが止まったときに前の版が残ることのケース、`ST-NFR-007-01` の対象の書き方）は、この改訂に含めず、ST の改訂の機会に扱う。公開用ビューアのケースは [HLD 4.20.5](https://github.com/jj1xgo/findsummits/blob/5cad4a5/docs/30_HLD.md#4205-未決事項と後続) の 5「`FR-020` の ST にケースを足す」に残す（[ADR-SRS-073](ADR-SRS-073-align-srs-wording-with-hld-decisions.md) の Decision 5 と同じ扱い）。
