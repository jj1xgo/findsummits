# ADR-SRS-057: 最低動作条件に CPU の性能下限を設けない

| 状態 | 採用・実装済み |
| 決定日 | 2026-09-25 |

## Context

[NFR-006](../20_SRS.md#nfr-006-可搬性環境) は [環境定義](../01_environment.md) に定めるスペックを最低動作条件とする。
環境定義は従来、開発に使うマシンの CPU（AMD Ryzen 7 2700）・メモリ・スワップ・ディスク容量をそのまま条件として掲げていた。
2026-09-25 時点で開発マシンの CPU は AMD Ryzen 7 5700X に替わっており、型番を並べた条件は機械を替えるたびに実物と食い違う。

解析の完走を左右するのはメモリとスワップ（[NFR-002](../20_SRS.md#nfr-002-メモリ使用量)）とディスクで、
CPU の性能が効くのは処理時間（[NFR-005](../20_SRS.md#nfr-005-処理時間目標)）である。

## Decision

1. 環境定義の最低動作条件に CPU の性能下限を設けない。CPU は環境定義の「参考: 開発に使っているマシン」に記録する。
2. [NFR-005](../20_SRS.md#nfr-005-処理時間目標) の処理時間目標と、[ST](../70_ST.md) の `ST-NFR-005-01` の判定
   （目標未達は不合格として記録し、利用上問題ないと判断する場合は許容判断を別に記録する）は変えない。
   処理時間の試験では、ST の記録項目どおり実行環境を記録する。
3. ディスクの条件は、開発マシンの容量（457.38 GiB）ではなく、全国処理範囲のタイルキャッシュの見積り（150 GB 以上の空き）で表す。

## Alternatives

**(A) 現行の CPU（Ryzen 7 5700X）を最低動作条件にする**

却下。最低動作条件が上がり、それより遅い CPU の環境が保証外になる。CPU は解析の完走を左右しない。

**(B) 旧 CPU（Ryzen 7 2700）を最低動作条件のまま残す**

却下。実物と食い違い、次に機械を替えたときにも同じ食い違いが起きる。

## Consequences

- CPU が遅い環境も最低動作条件を満たしうる。その環境では [NFR-005](../20_SRS.md#nfr-005-処理時間目標) の処理時間目標を満たさないことがあり、`ST-NFR-005-01` で記録される。
- SRS の文面は変えない。[NFR-006](../20_SRS.md#nfr-006-可搬性環境) が参照する環境定義の中身が変わる。
- 反映先: [環境定義](../01_environment.md)。
