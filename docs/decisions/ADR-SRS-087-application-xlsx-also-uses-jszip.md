# ADR-SRS-087: 申請書 XLSX の生成も JSZip を使う

| 項目 | 内容 |
|---|---|
| 状態 | 採用・未実装 |
| 決定日 | 2026-11-10 |

---

## Context

ソフトウェア要件仕様書（SRS）の [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成)（申請書 XLSX 生成）は、入力のライブラリを SheetJS だけとし、異常系も SheetJS が取得できないときだけを定めていた。

2026-11-10 に、申請書の `A6` でのウィンドウ枠の固定を、SheetJS CE で書いた後に JSZip で書き足すと決めた（[ADR-HLD-010](ADR-HLD-010-xlsx-freeze-pane-written-with-jszip.md)）。SheetJS CE は固定を書けないためである。これで申請書の生成も JSZip に依存するようになり、[FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) の入力表が、[文書管理ルール](../CLAUDE.md)の「各 FR の入出力テーブルは、該当する全外部I/F を列挙する」に合わなくなった。

## Decision

1. [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) の入力のライブラリを「SheetJS・JSZip」にし、JSZip はウィンドウ枠の固定の書き足しに使うと備考に書く。
2. [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) の異常系の「XLSX 生成ライブラリ」を「SheetJS・JSZip」にする。どちらかが取得できていなければ、申請書のエクスポートを実行できない旨を示す。
3. [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の「申請書」ボタンの説明にも、JSZip を使うことを添える。
4. 申請書に何を出すか（要求の意味）は変えない。CDN のライブラリは Leaflet・SheetJS・JSZip の 3 つのままで、[§3.4](../20_SRS.md#34-外部システム依存関係環境) とライブラリの外部 I/F の行は変えない（[FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) はすでに使う FR に挙がっている）。

## Alternatives

- SheetJS の配布物に含まれる ZIP の処理で `<pane>` を書き足し、JSZip に依存しない: 確かめていない。決定性を含めて確かめ直す手間が要り、JSZip は申請エビデンス ZIP のためにどのみち読む。却下（持ち主の判断、2026-11-10）。

## Consequences

- JSZip が取得できず SheetJS が取得できたとき、これまでの仕様では申請書を出せたが、出せなくなる。どちらのライブラリも同じ CDN の取り方（[HLD](../30_HLD.md) の DEC129）で読むので、片方だけが取れない場面は少ない。
- 概要設計書（HLD）の 4.11.2 の冒頭、4.11.3 の異常系、DEC120 を、SheetJS と JSZip の両方を確かめる形にそろえた。
