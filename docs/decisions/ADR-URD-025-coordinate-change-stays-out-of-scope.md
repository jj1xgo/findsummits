# ADR-URD-025: 既存サミットの座標変更をスコープ外のままにし、理由を事実に合わせる

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-11 |

---

## Context

[URD §6](../10_URD.md#6-スコープ外対象外) とソフトウェア要件仕様書（SRS）の [3.6](../20_SRS.md#36-スコープ外) は、既存サミットの座標変更申請を「座標は概ね正しいと判断し自動識別しない」としてスコープ外にしていた。2026-10-11 に確かめると、座標の変更を申請した記録が実際にあった。

- 山岳データ登録変更リスト（[SOURCES](../../ref/SOURCES.md#山岳データ登録変更リスト)）の 2024〜2026 年の 3 ページで、変更の行は 368 行（同じ行の重複を除く）。そのうち ID の欄を除く本文に「位置」を含む行は 22 行だった。その 22 行のうち 11 行は、備考の欄に登頂・現地・標識・看板・モニュメントのどれかの語を含み、地理院地図で確かめたと書く行もあった。
- 申請書テンプレート（[SOURCES](../../ref/SOURCES.md#sota-summit-list-revision-requestxlsx)）の変更の行は、山岳名と標高の列だけで、位置の列は無い。位置の変更の記入例も指示も無い（[ADR-URD-024](ADR-URD-024-ur-004-other-action-wording.md)）。
- findsummits の差分線（`coord_diff`。[FR-009](../20_SRS.md#fr-009-sotaリスト突合match_status-判定)）は、SOTA 登録座標と解析座標の差分線で、ピークとアクティベーションゾーン（AZ）の中の既存サミットを結ぶものを含む。ビューアは差分線を地図に破線で描く（[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様)）。SRS と概要設計（HLD）は、差分線の長さに応じた扱い（しきい値）を定めていない。

## Decision

1. 既存サミットの座標変更申請は、引き続きスコープ外とし、ツールは自動識別しない（申請行も作らず、候補を目立たせることもしない）。
2. 理由を「座標は概ね正しいと判断し」から、次に改める。座標の変更は実際に申請されているが、位置の変更は申請者が地図や現地で確かめて申請するものとし、ツールは AZ の中の既存サミットとピークの座標の差を、ビューアの差分線で示すにとどめる（持ち主の判断、2026-10-11）。
3. [URD §6](../10_URD.md#6-スコープ外対象外) の文を改め、SRS の [3.6](../20_SRS.md#36-スコープ外) は同じ意味の短い文にして URD §6 を指す。確定済みの URD の補足として、URD に注記を置く（[ADR-URD-023](ADR-URD-023-ur-018-publish-wording.md) と同じ形）。
4. 同じバンドの中の標高の変更（[URD §6](../10_URD.md#6-スコープ外対象外) の「バンドをまたがない標高変動」）の扱いは変えない。

## Alternatives

- **(B) ビューアで位置の変更の候補を目立たせる**: SRS・HLD には、差分線の長さに応じた扱いの定めが無く、目立たせる基準が決まっていない。採らないことは持ち主の判断（2026-10-11）。
- **(C) 位置の変更の申請行を作る**: テンプレートの変更の行に位置の列が無く、位置の変更の記入例も指示も無い。採らないことは持ち主の判断（2026-10-11）。

## Consequences

- [URD §6](../10_URD.md#6-スコープ外対象外) と SRS の [3.6](../20_SRS.md#36-スコープ外) の座標変更の行の理由を直した。ツールの振る舞いは変わらない。
- AZ の中の既存サミットについては、申請者はビューアの差分線（破線）を見て、位置の変更を自分で判断できる。
- 登録変更リストを、SOURCES でこの判断の参照資料にも挙げた。
