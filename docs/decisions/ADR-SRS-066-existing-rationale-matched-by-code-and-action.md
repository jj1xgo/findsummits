# ADR-SRS-066: 既存の登録の根拠の編集値はアクションも合わせて照合する

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-05 |

## Context

[SRS §8.2.2](../20_SRS.md#822-localstorage-編集内容詳細仕様) と [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の「入力内容の保持（localStorage）」は、山岳名・通常 rationale の編集値を保存・照合する識別値を、new / dominant のピークはピーク座標、既存サミット（band_change の matched 登録・通常 delete）は正式 SummitCode と定めていた。[HLD 4.19](../30_HLD.md#419-fr-019-html-ビューア機能仕様) の設計で、次の問題があると分かった。

- 同じ正式コードの登録が、前の世代では変更（band_change）の候補で、新しい世代では通常の削除（delete）の候補になることがある（主ピークの変化など）。その逆もある。
- 正式コードだけで照合すると、前の世代の変更の根拠（[FR-009](../20_SRS.md#fr-009-sotaリスト突合match_status-判定) の ※5 の書式を編集した文）が、今回の削除の行の rationale に当たる。その文は、申請書の列 I（[FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成)）と ZIP の GeoJSON（[FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成)）に削除の根拠として出る。
- §8.2.2 の「一致しない保存値（…既存登録が不在や対象外になった）は適用せず」が、アクションの変化を含むかは、字句から確定できない。

HLD だけで照合の条件を足すと、HLD と SRS の字句が食い違う。[開発ガイド 6.3](../03_development.md#63-変更するときの手順) は、影響する文書を同じ変更で直すことを求めている。

## Decision

1. [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の「入力内容の保持（localStorage）」と [SRS §8.2.2](../20_SRS.md#822-localstorage-編集内容詳細仕様) の「山岳名・通常 rationale の保存単位」で、既存サミットの識別値を、正式 SummitCode とアクション（band_change か delete）の組に改める。
2. [SRS §8.2.2](../20_SRS.md#822-localstorage-編集内容詳細仕様) の「山岳名・通常 rationale の引き継ぎ」の、一致しない保存値の例に「既存登録のアクションが変わった」を足す。適用せず、件数と識別値を利用者に知らせ、前世代の保存値を保持する扱いは変えない。
3. 保存の形と照合の手順は、[HLD 4.19](../30_HLD.md#419-fr-019-html-ビューア機能仕様) の D134 で定める。

## Alternatives

**(A) 正式 SummitCode だけで照合する（改める前の SRS の字句どおり）**

却下。アクションが変わった登録に、別のアクションの根拠の文が黙って当たる（持ち主の判断、2026-10-05）。

**(B) HLD だけで条件を足し、SRS は改訂の機会まで改訂の候補として残す**

却下。HLD と SRS の字句が食い違ったまま残る（2026-10-05 の [HLD 4.19](../30_HLD.md#419-fr-019-html-ビューア機能仕様) の計画レビューで指摘を受け、持ち主が判断した）。

## Consequences

- 反映先: [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様)、[SRS §8.2.2](../20_SRS.md#822-localstorage-編集内容詳細仕様)、[HLD 4.19](../30_HLD.md#419-fr-019-html-ビューア機能仕様)（D134）。
- 新設のピークの照合（ピーク座標）は変えない。追加の候補のアクションは add だけなので、アクションを足す必要が無い。
- 除外台帳の識別キー（[SRS §8.2.3](../20_SRS.md#823-除外台帳)）は、もともとアクションを含むので変えない。担当者指定削除の照合（正式 SummitCode）も変えない。
- [ST](../70_ST.md) の [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の試験に、変更から削除に変わった登録の根拠が当たらないケースを足す（[HLD 4.19](../30_HLD.md#419-fr-019-html-ビューア機能仕様) の 4.19.5 の 6）。ST の改訂の機会に合わせる。
