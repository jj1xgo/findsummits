# ADR-URD-023: UR-018 の「生成できること」を「公開できること」に改める

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-09 |

---

## Context

[UR-018](../10_URD.md#ur-018) は「公開用の静的 HTML ビューア（閲覧専用）を生成できること」と書く。一方、SRS では [FR-013](../20_SRS.md#fr-013-html-ビューア生成) が生成するのは作業用ビューアだけで、公開用ビューアは [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) が静的ホスティングで配信する（利用者が置いた GeoJSON を、閲覧専用のテンプレートとともに配信する）。公開用ビューアはツールが生成するものではないので、[UR-018](../10_URD.md#ur-018) の字面が実現手段と合わない。この文言は、分割前の UR-006 から引き継いだものである（[ADR-URD-022](ADR-URD-022-split-ur-006-into-geojson-and-two-viewers.md)）。

## Decision

[UR-018](../10_URD.md#ur-018) の「生成できること」を「公開できること」に改める。ほかの字句と、SRS の「対応 UR」の追跡は変えない。確定済みの URD の補足として、URD に注記を置く。記録は、SRS の改訂（[ADR-SRS-073](ADR-SRS-073-align-srs-wording-with-hld-decisions.md)）と同時に行う。

## Alternatives

- **(a) 今のままにし、読み替えを注記する**: 字面と実現手段のずれが残り、読むたびに注記が要る。

## Consequences

- URD の [UR-018](../10_URD.md#ur-018) の文言と注記を直した。
- [ADR-URD-022](ADR-URD-022-split-ur-006-into-geojson-and-two-viewers.md) に、[UR-018](../10_URD.md#ur-018) の文言を改めたことを示す注を置いた。
- SRS で [UR-018](../10_URD.md#ur-018) の文言を引いている箇所があれば、同じ字句に合わせた。
