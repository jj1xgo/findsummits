# ADR-SRS-060: 解析パイプライン制御は起動前提条件の検査のために日本全土リストと北方領土除外メッシュリストを読む

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-02 |

## Context

[ADR-SRS-059](ADR-SRS-059-tile-fetch-completion-record.md) で、[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) はフェーズ2 の起動前提条件「標高タイルのローカルキャッシュ取得完了」を標高タイル取得完了記録で判定することにした。記録は取得を最後まで終えた 1次メッシュコードの集合なので、判定には、解析に要るメッシュの集合が要る。ところが [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) は日本全土1次メッシュコードリストを直接読まず（入力表）、北方領土除外メッシュリストも読まない（[ADR-SRS-053](ADR-SRS-053-northern-territories-tile-intersection-and-excluded-meshes.md) の Decision 3）。

- 検査は、前回の出力を消す前に [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) の中で済ませる必要がある（[HLD 2.9.3](../30_HLD.md#293-同時起動の排他)）。解析を行う [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) に任せると、検査の前に前回の出力が消える。
- 記録をメッシュの集合のまま保てば、1次メッシュコードリストを分けた取得をすべて正常に終えた場合と、一度に取得した場合を同じに扱える（[HLD 4.1.2](../30_HLD.md#412-処理の流れ)）。
- フェーズ4 の [FR-009](../20_SRS.md#fr-009-sotaリスト突合match_status-判定) は、ローカルキャッシュのすべての PNG の mtime の最大値を `gsi_tile_latest_date` にする。[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) はフェーズ4 の単独起動の前提を「標高タイルのローカルキャッシュの存在」としているので、取得が途中で止まったキャッシュでも先へ進む。

## Decision

1. [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) は、起動前提条件の検査のためにだけ、日本全土1次メッシュコードリストと北方領土除外メッシュリストを読む。入力表に 2 行を足す。[SRS §8.1](../20_SRS.md#81-内部データ一覧) の No.4・No.16 の参照先と、北方領土除外メッシュリストを読む FR を並べた箇所（[FR-017](../20_SRS.md#fr-017-n03-行政区域前処理データ準備) の出力表と説明、[§8.2.1](../20_SRS.md#821-n03-前処理済みファイル詳細仕様)）にも [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) を足す。1次メッシュコードリストを省略したときに各 FR が自分の既定値を使うことは変えない。
2. 解析に要るメッシュは、1次メッシュコードリストを指定しないときは、日本全土1次メッシュコードリストから北方領土除外メッシュを除いたものとする。指定したときは、そのコードから、日本全土1次メッシュコードリストに無いものと北方領土除外メッシュを除いたものとする（[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) がスキップするのと同じ基準）。警告とスキップは今までどおり [FR-001](../20_SRS.md#fr-001-標高タイル事前取得)・[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) が行い、[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) は出さない。
3. 標高タイル取得完了記録を、フェーズ2 に加えて、フェーズ4 の単独起動の前提（標高タイルのローカルキャッシュ）の判定にも使う。フェーズ3 の単独起動でタイルを検査すること（HLD で足した検査）と、フェーズ3・4 の単独起動で解析に要るメッシュを日本全土とすることは、HLD で定める。
4. [ADR-SRS-053](ADR-SRS-053-northern-territories-tile-intersection-and-excluded-meshes.md) の [Decision 3](ADR-SRS-053-northern-territories-tile-intersection-and-excluded-meshes.md#3-除外メッシュは全工程でリスト外メッシュと同じに扱う) のうち、[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) の項（日本全土1次メッシュコードリストを直接読まない方針のため、除外メッシュリストも直接読まない）を supersede する。除外メッシュの警告とスキップを [FR-001](../20_SRS.md#fr-001-標高タイル事前取得)・[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) で行うことは変えない。
5. フェーズ4 の単独起動の前提に挙げている `merged_peak.geojson` を、[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) の入力表と [SRS §8.1](../20_SRS.md#81-内部データ一覧) の No.11 の参照先に足す（2026-10-02、[HLD 4.23](../30_HLD.md#423-fr-023-解析パイプライン制御) のレビューで、前提の説明にあるのに台帳に無いと分かったため）。

## Alternatives

**(A) 標高タイル事前取得（[FR-001](../20_SRS.md#fr-001-標高タイル事前取得)）が記録に「日本全土を取り終えた」印を書き、[FR-023](../20_SRS.md#fr-023-解析パイプライン制御) はリストを読まずに印を見る**

却下。記録の中身がメッシュの集合でなくなる。1次メッシュコードリストを指定した実行では、日本全土1次メッシュコードリストに無いコードを [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) が見分けられず、[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) なら警告して飛ばすコードで止まる。

**(B) 検査を [FR-001](../20_SRS.md#fr-001-標高タイル事前取得) の起動口に頼む**

却下。[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) に検査だけの働きが増え、起動前提条件の充足検査を [FR-023](../20_SRS.md#fr-023-解析パイプライン制御) が行うという定めとずれる。

**(C) フェーズ4 の前提は、ローカルキャッシュの存在のままにする**

却下。取得が途中で止まったキャッシュで、[FR-009](../20_SRS.md#fr-009-sotaリスト突合match_status-判定) が `gsi_tile_latest_date` を算出する。
