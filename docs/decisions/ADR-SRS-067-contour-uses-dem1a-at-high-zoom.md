# ADR-SRS-067: ビューアの等高線は大きいズームで DEM1a を使う

| 状態 | 採用・未実装 |
| 決定日 | 2026-10-05 |

## Context

[ADR-SRS-015](ADR-SRS-015-contour-overlay.md) は、HTML ビューアの等高線オーバーレイのデータを地理院標高タイルの DEM5a・DEM5b・DEM5c・DEM10b とし、DEM1a（ズーム 17、1m メッシュ）は「カバレッジが限定的なため現時点では採用しない。HLD で改めて評価する」とした。[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) と [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の入力の表と、[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の等高線オーバーレイの説明は、この 4 種を挙げている。[HLD 3.19](../30_HLD.md#319-fr-019-html-ビューア機能仕様) で地図の描画を設計するときに、この評価を行った。

- 等高線は、表示範囲のタイルだけをブラウザから読む。DEM1a の無いタイルは DEM5a〜5c、それも無ければ DEM10b に切り替えて描くので、DEM1a を足しても、描ける範囲は DEM1a を使わない場合より減らない。
- 国土地理院のタイル一覧（[SOURCES](../../ref/SOURCES.md) の「国土地理院標高タイル」の参照 URL）は、DEM1a を `dem1a_png` としてズーム 1〜17 で提供している（2026-10-05 に確かめた）。
- モックアップ（`docs/mockup/viewer_mockup.html`）は、ズーム 17 以上で DEM1a を読み、無ければ DEM5a〜5c に切り替える形で作られ、持ち主が見た目を確かめている。持ち主は、完成したビューアの見た目がモックアップから変わらないことを求めた。
- [URD §5](../10_URD.md#5-前提制約)・[§6](../10_URD.md#6-スコープ外対象外) と [SRS §3](../20_SRS.md#3-システムアーキテクチャ概要)・[§10](../20_SRS.md#10-制約前提条件)・[§11](../20_SRS.md#11-スコープ外) は、限定を付けずに「標高データは DEM5a〜DEM10b のみ使用」「DEM1a は採用しない」と書いている。採用しない理由（データ量が DEM5 の 25 倍、精度の向上がわずか。[ADR-SRS-002](ADR-SRS-002-dem-hierarchy-fallback.md)）は解析についてのもので、表示範囲のタイルだけを読む等高線には当てはまらない。

解析（[FR-001](../20_SRS.md#fr-001-標高タイル事前取得) から [FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) など）が使う標高タイルは、この評価の対象ではない。

## Decision

1. ビューアの等高線オーバーレイは、地図のズーム 17 以上で DEM1a を読み、DEM1a の無いタイルは DEM5a・DEM5b・DEM5c、それも無ければ DEM10b の順に切り替える。ズーム 16 以下の読み方と、ズームごとの選び方の詳細は [HLD 3.19](../30_HLD.md#319-fr-019-html-ビューア機能仕様) の D143 で定め、ADR-SRS-015 の Decision のタイルの選び方の字句に代える。
2. [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) と [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の入力の表、[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の等高線オーバーレイの説明、[SRS §6.2.9](../20_SRS.md#629-地理院標高タイル) のズームレベルとタイル URL に DEM1a を足す。[SOURCES](../../ref/SOURCES.md) の「国土地理院標高タイル」と[用語集](../00_GLOSSARY.md)にも足す。
3. [URD §5](../10_URD.md#5-前提制約)・[§6](../10_URD.md#6-スコープ外対象外) と [SRS §3](../20_SRS.md#3-システムアーキテクチャ概要)・[§10](../20_SRS.md#10-制約前提条件)・[§11](../20_SRS.md#11-スコープ外) の該当行に「解析の」という限定を付け、DEM1a を採用しない行には「HTML ビューアの等高線は除く」を足す。解析の範囲は変えないので、URD の改訂もこの ADR で扱う。
4. [ADR-SRS-015](ADR-SRS-015-contour-overlay.md) の冒頭に、dem1a の扱いをこの ADR で改めた旨の補足を足す。

## Alternatives

**(A) DEM1a を使わない（ADR-SRS-015 の決定のまま）**

却下。大きいズームの等高線が DEM5 の拡大になって粗くなり、モックアップから見た目が変わる（持ち主の判断、2026-10-05）。

**(B) URD の改訂を別の ADR（ADR-URD）に分ける**

却下。URD の改訂は、解析の範囲を変えずに字句の限定を付けるだけで、決定の中身はこの ADR と同じである。ADR が 2 本に分かれると、同じ決定を 2 か所で追うことになる（持ち主の判断、2026-10-05）。

## Consequences

- 反映先: [URD §5](../10_URD.md#5-前提制約)・[§6](../10_URD.md#6-スコープ外対象外)、[SRS §3](../20_SRS.md#3-システムアーキテクチャ概要)・[§6.2.9](../20_SRS.md#629-地理院標高タイル)・[§10](../20_SRS.md#10-制約前提条件)・[§11](../20_SRS.md#11-スコープ外)、[FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様)、[FR-020](../20_SRS.md#fr-020-公開用ビューア配信)、[用語集](../00_GLOSSARY.md)、[SOURCES](../../ref/SOURCES.md)、[ADR-SRS-015](ADR-SRS-015-contour-overlay.md)、[HLD 3.19](../30_HLD.md#319-fr-019-html-ビューア機能仕様)（D143）。ADR-SRS-015 が HLD に送った DEM1a の評価は、この ADR で済んだ。
- 解析の入力（DEM5a〜5c・DEM10b のローカルキャッシュ）は変えない。DEM1a はローカルキャッシュに置かない。
- 等高線は目安で、標高・コル位置の根拠に使わないという [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の位置付けは変えない。
- [ST](../70_ST.md) の [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) の試験に、DEM1a のある地域、DEM1a が無く DEM5 のある地域、DEM10b だけの地域のそれぞれで、ズーム 17 の等高線が描けるケースを足す（[HLD 3.19](../30_HLD.md#319-fr-019-html-ビューア機能仕様) の 3.19.5 の 9）。ST の改訂の機会に合わせる。
