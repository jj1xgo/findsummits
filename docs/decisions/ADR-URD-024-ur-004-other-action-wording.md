# ADR-URD-024: UR-004 の「その他」の説明を申請書テンプレートと登録変更リストの記録に合わせる

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-11 |

---

## Context

[UR-004](../10_URD.md#ur-004) は、申請書のアクション「その他」を「名称変更・座標変更等、追加/変更/削除に分類されないケースに使用するアクション区分」と説明していた。ソフトウェア要件仕様書（SRS）の [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様) と [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) も、名称変更・座標変更を「その他」アクションとして引いていた。2026-10-11 に確かめると、この説明はテンプレートの記入例とも申請の記録とも合わなかった。

- 申請書テンプレート（[SOURCES](../../ref/SOURCES.md#sota-summit-list-revision-requestxlsx)）の A 列の入力規則には、追加・削除・変更・その他の 4 つがある。「その他」の用途の定めは無い。
- 同じテンプレートの記入例は、山名の変更（曽田山 → 祖田山）を「変更」で書いている。変更前・変更後の列は山岳名と標高だけで、位置の列は無い。位置の変更の記入例や書き方の指示は無い。
- 山岳データ登録変更リスト（[SOURCES](../../ref/SOURCES.md#山岳データ登録変更リスト)）の 2024〜2026 年の 3 ページでは、アクションの欄が追加・変更・削除・その他の行は、追加 93・変更 368・削除 15 の計 476 行（同じ行の重複を除く）で、「その他」は 0 行だった。変更の行のうち、ID の欄を除く本文に「位置」を含む行は 22 行で、位置の変更も「変更」で申請されていた。

## Decision

1. [UR-004](../10_URD.md#ur-004) の「その他」の説明を、「テンプレートの入力規則にあるアクション区分で、テンプレートは用途を定めていない。名称の変更はテンプレートの記入例で『変更』と書かれ、登録変更リストの記録では名称や座標の変更も『変更』で申請されている」と改める。ツールが「その他」の行を生成しないことと、必要なら申請者が手動で記入することは変えない。
2. 名称変更・座標変更の申請を自動識別しないこと（[URD §6](../10_URD.md#6-スコープ外対象外)、SRS の [3.6](../20_SRS.md#36-スコープ外)）は変えない。[UR-004](../10_URD.md#ur-004) は [UR-003](../10_URD.md#ur-003) と [URD §6](../10_URD.md#6-スコープ外対象外) を、SRS の 2 か所は [UR-003](../10_URD.md#ur-003) と SRS の [3.6](../20_SRS.md#36-スコープ外) を、その理由として指す。
3. 確定済みの URD の補足として、URD に注記を置く（[ADR-URD-023](ADR-URD-023-ur-018-publish-wording.md) と同じ形）。

## Alternatives

- **(a) 今のままにする**: 申請者が名称や位置の変更を「その他」で書くと、テンプレートの記入例と申請の記録に反する。ツールは「その他」の行を作らないが、手で書く申請者を誤らせる。
- **(b) 「その他」の用途を定める**: テンプレートにも申請の記録にも根拠が無く、SOTA 日本支部が決めることである。

## Consequences

- URD の [UR-004](../10_URD.md#ur-004) の文言と注記、SRS の [FR-019](../20_SRS.md#fr-019-html-ビューア機能仕様)・[FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) の該当の文を直した。出力（申請書 XLSX）は変わらない。
- 登録変更リストを参照資料として SOURCES に足した。ツールの入力ではないので、用語集には足していない。
- 既存サミットの位置の変更を識別対象にするかは、別に扱う（[URD §6](../10_URD.md#6-スコープ外対象外) の見直し）。

## 追記（2026-10-19）: 登録変更リストを突合の入力にした

Consequences の「ツールの入力ではないので、用語集には足していない」は、[ADR-URD-029](ADR-URD-029-pending-applications-in-matching.md) で改めた。登録変更リストを、申請済みで現行 SOTA リストに未反映の申請を識別する突合の入力にし、用語集に足した。この ADR の決定（[UR-004](../10_URD.md#ur-004) の「その他」の説明）は変わらない。
