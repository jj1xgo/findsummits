# ADR-SRS-085: SRS の FR-021 の 2 回目の見直しで、出力の行から ZIP のファイル名の定義を指す

| 項目 | 内容 |
|---|---|
| 状態 | 採用・実装済み |
| 決定日 | 2026-10-13 |

---

## Context

2026-10-13 に、改訂した多視点のレビュー（spec-panel）で、ソフトウェア要件仕様書（SRS）の §4.7 の [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成)・[FR-012](../20_SRS.md#fr-012-サミット一覧申請内容反映版生成)・[FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) と §4.8 の [FR-020](../20_SRS.md#fr-020-公開用ビューア配信) を、[ADR-SRS-084](ADR-SRS-084-srs-fr-011-021-020-review-blank-region-warning-and-public-viewer-fetch-failure.md) の反映の後に 2 回目として見直した（[#204](https://github.com/jj1xgo/findsummits/issues/204)）。ADR-SRS-084 で足した文に、ほかの節・FR・台帳との食い違いは無く、次の 1 件が見つかった。

[FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) の出力「申請エビデンス ZIP（パッケージング仕様）」の行と本文は、その詳細仕様の [§6.2.8](../20_SRS.md#628-申請エビデンス-zipパッケージング仕様) を指していなかった。ZIP のファイル名 `sota_evidence_YYYYMMDD.zip`（[ADR-SRS-065](ADR-SRS-065-evidence-zip-filename-export-date.md)）は §6.2.8 にだけあり、[FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) から辿れなかった。兄弟の [FR-011](../20_SRS.md#fr-011-申請書-xlsx-生成) の出力の行は [§6.2.1](../20_SRS.md#621-申請書-xlsx) を、[FR-020](../20_SRS.md#fr-020-公開用ビューア配信) の出力の行は [§6.2.7](../20_SRS.md#627-公開用ビューア閲覧専用静的ホスティング配信) を指している。

## Decision

[FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) の出力の行の備考に、ファイル名は [§6.2.8](../20_SRS.md#628-申請エビデンス-zipパッケージング仕様) を参照すると書く。同梱ファイルの一覧（[FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) の「説明」の表と §6.2.8 の表）は変えない。

## Alternatives

- **(a) ファイル名を [FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) に書き写す**: 同じ定義が 2 か所になり、直したときに追従が漏れる。参照にとどめた。

## Consequences

- SRS の [FR-021](../20_SRS.md#fr-021-申請エビデンス-zip-生成) の出力の行の備考に参照を 1 つ足した。要求の中身は変わらない。
- 概要設計書（HLD）とシステムテスト仕様書（ST）に直すところは無い。
