# ADR-SRS-052: 検出網羅性の受入基準

| 状態 | 採用・未実装 |
| 決定日 | 2026-09-21 |

> **補足（2026-09-23）:** 「SRS の関連残件」の北方領土除外と全欠如停止の境界は、[ADR-SRS-053](ADR-SRS-053-northern-territories-tile-intersection-and-excluded-meshes.md) で決着した。

## Context

[UR-001](../10_URD.md#ur-001) の全国ピーク検出と [UR-007](../10_URD.md#ur-007) の独立峰検出は網羅性を要求するが、
従来の [NFR-001](../20_SRS.md#nfr-001-精度プロミネンス判定) は出力のプロミネンス閾値を定めるだけで、
未検出ピークを測る独立した基準を持たなかった。ST の全国完了件数・著名峰サンプルだけでは既知の取りこぼしを判定できない。

## Decision

**全国処理範囲の一致と、事前確定した代表的な基準ピークの検出漏れ0件・再現率100%を必須にする。**
SRS の既存閾値規則を維持したまま NFR を拡張し、対応する全国/独立峰の要求へ追跡する。

- 期待メッシュ集合は出典・URD から製品入力と独立に導き、製品リストと正常完了集合を別々に照合する。
  [ADR-URD-009](ADR-URD-009-takeshima-exclusion.md) の竹島メッシュ除外と
  [ADR-URD-005](ADR-URD-005-northern-territories-exclusion.md) のタイル単位除外を区別する。
- 基準は固定 DEM と仕様上の最終閾値を満たす対象を独立確認し、許容位置・根拠・代表区分・入力版・設定とともに試験前に固定する。
  正解の独立性は確認者の人数ではなく根拠の由来で担保する。SOTA 登録や本製品の過去版を含む出力は正解そのものにしない。
- 測定地点は通常解析と必要な広域解析の最終統合後、SOTA 突合前の全国 `merged_peak.csv`。
  一意照合、重複割当なし、コル確定、最終閾値以上を成功条件とし、未確定候補の存在では代用しない。
  広域代表等で既存仕様上許される stability 値は認める。申請除外や担当者指定削除を本測定へ適用しない。
- 地域・登録有無・通常/広域・海面確定・DEM・境界/近接・既知の漏れを代表区分として ST に固定する。
  DEM は入力キャッシュのピーク画素または陸上 Key コル画素に基づく区分とし、製品出力の列追加を要求しない。
- 空集合、必須区分不足、未確定、曖昧な照合は合格にしない。結果を見て基準を変更する場合は独立根拠・承認・改版・再評価を要し、旧結果を保存する。
  適格性確認済みピークを製品の解析上限の都合で除外しない。新たな漏れは欠陥として処置し回帰基準へ追加する。

要求の正本は [NFR-001](../20_SRS.md#nfr-001-精度プロミネンス判定)、記録項目・選定表・照合/改版・負例は
[ST §3.8.2](../70_ST.md#382-検出網羅性の基準セットと判定手順)、用語は
[用語集](../00_GLOSSARY.md#検出網羅性の受入)に置く。比較検討とレビュー経緯は [採用時仕様案](research/detection-completeness-spec.md) に残す。
ST の測定経路と SRS RTM の直接寄与を区別し、経路上にあるという理由だけで既存 FR の対応印を増やさない。

## Alternatives

| 案 | 採らない理由 |
|---|---|
| 現行 SOTA 全登録を正解として全件照合 | 登録ずれ・重複・削除対象が含まれ、未登録ピークも検証できない |
| 全国全ピークの独立正解を構築して全件照合 | 正解自体の完全性の調査を要し、今回の枠組み整備を超える |
| 独立母集団から無作為抽出し信頼区間を評価 | 母集団・抽出設計を別途要する。確認済みの漏れを許容しない今回の合否とは目的が異なる |
| 再現率を別 NFR として新設 | 閾値に基づく適格性と検出の成立を合わせた品質要求として既存要件の小節に分ける方が追跡しやすい |

## Consequences

有限の基準セットに対する受入証拠を得る方式であり、未知の全ピークに漏れがない数学的証明・統計的保証ではない。
URD の目標を緩和せず、合格の意味と限界を報告する。偽陽性・出力全数の精度・申請成果物等の既存検証を置き換えない。

後工程では、必須区分を満たす基準ピーク全レコード、独立根拠、許容位置、期待メッシュ集合を実データで整備する。
照合・集計・証跡保存を実装し、通常/広域を含む全国解析と、閾値・同標高頂部・近接峰・境界・窓外コルの補助試験を実施する。
具体的なファイル形式や照合ツールは後工程の設計で決める。基準セットを製品の必須入力にはしない。
基準訂正による保存済み出力の再照合は、新版の事前固定と出力の内容識別を伴わせ、解析前から固定した試験と区別する。
解析コード・入力・設定の変更時は解析を再実行する。

基準全件作成・全国実測・補助試験は本決定時点では未実施。HLD 以降へ引き継ぐ作業であり、仕様反映や lint 成功を検出性能の実証とは扱わない。

**SRS の関連残件**: 北方領土のタイル取得除外（[ADR-SRS-018](ADR-SRS-018-northern-territories-skip-at-tile-fetch.md)）と、
[FR-004](../20_SRS.md#fr-004-33メッシュ結合解析オーケストレーション) の対象メッシュ内タイル全欠如による停止条件の整合は別途決着を要する。
意図的な全欠如の発生条件と隣接窓への影響は未実測であり、海岸付近の非除外タイルや過去のサンプル404だけで永久的な処理不能とは断定しない。
この論点は従来の175メッシュ完了要求にも関係し、本受入基準を設けたことで明確になった既存規則間の境界である。
停止を試験側だけで正常完了へ数え替える方法は採らない。全国受入の実行前提として、意図的除外・取得失敗・未整備を区別する方針を SRS 残件として HLD 移行前に確定する。
本決定だけで当該残件が解消した、または現行仕様のままで全国完走できると主張しない。
